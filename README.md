# LUDUS Unity SDK

SDK Unity plugável para coleta de telemetria de jogos educacionais e integração
com a plataforma LUDUS Acompanha.

> Projeto em desenvolvimento. A API pública e o processo de instalação ainda
> podem mudar antes da primeira versão estável.

## Objetivo inicial

Permitir que diferentes jogos Unity/WebGL registrem sessões, interações e
eventos semânticos em um contrato comum, preservando a lógica pedagógica de
cada jogo.

## Estado atual

Estrutura inicial do pacote Unity Package Manager.
